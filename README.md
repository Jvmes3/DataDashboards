1. United Way Polling Data Dashboard

Platform: Microsoft Power BI
Organization: MyVillage Project

Overview

Developed an analytics dashboard to evaluate survey polling data measuring generational awareness, recognition, and understanding of United Way organizations in Jacksonville.

Key Features <br/>
Generational comparison (Gen Z, Millennials, Gen X, Baby Boomers)<br/>
Awareness and engagement metrics<br/>
Trend visualization through interactive charts<br/>
Stakeholder-ready reporting for strategic outreach decisions<br/>
Dynamic filtering by age group and response categories<br/>
Business Value<br/>

Helped identify awareness gaps across demographics and supported data-driven outreach planning for nonprofit engagement initiatives.
